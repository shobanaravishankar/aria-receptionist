Setup (for the site owner)

Add your Retell values in demo-config.js:

window.RETELL_DEMO = {
  publicKey: "YOUR_RETELL_PUBLIC_KEY",   // API Keys → Public Keys
  agentId:   "YOUR_ARIA_VOICE_AGENT_ID", // Aria's agent id
  agentVersion: null                     // optional
};

Then allow localhost (and later your deployed hostname) on that public key in the Retell dashboard.
